# 和訳CSV 検証メモ（2026-11-17）

## 入手経路
- 本家: Civitai model 2018479「Danbooru tag complete csv」の `danbooru_translations_jp.csv`。
  Civitai の直接ダウンロードはログイン必須で取得不可だった。
- 実際に取得できたのは、同データセットの改変版を同梱する note 配布アプリ
  「Danbooru Character Tag Search」（まろちん）の配布 zip 内の同名ファイル。
  41,756 件 / 1,948,396 bytes。tools/translations/danbooru_translations_jp.csv に保存。

## 形式の実態
- tagcomplete 用「翻訳」ファイル＝タグ1件に日本語の検索エイリアスが複数、カンマ区切りで並ぶ。
  きれいな1対1訳ではない。先頭の語が最も訳として妥当（例: twintails→ツインテール、
  black_hair→黒髪、looking_at_viewer→カメラ目線）。後ろには検索語・ノイズが混ざる
  （long_hair→…黒髪ロング、金髪ロング 等）。
- 表示に使うなら「最初の日本語要素だけ」を抽出するのが前提。

## カバー率（こちらの辞書 140,782 件と突き合わせ、日本語要素あり）
- 全体: 38,633 件（27.4%）
- 一般カテゴリ: 25.2% / 一般の頻度上位3,000件では 52.8%、上位1,000件（全カテゴリ）66.5%
- スロット用グループ: hair 33% / eyes 34% / face 38% / attire 57% / backgrounds 27% / poses 39%

## 同梱サイズ
- 先頭訳のみ抽出・辞書に存在するタグだけに絞ると 38,633 件 / 約1.46MB（CSV）。

## ライセンス
- Civitai API の権限フラグ: クレジット不要・派生物可・別ライセンス可・商用可と緩い。
  再配布は可能と判断するが、出典は README 等に明記する。
- note 側の注意書き: 「改変済みファイルを再配布する場合は、元データセットの配布条件を確認」。

## 注意
- 自動翻訳中心で精度にムラ（smile→笑い 等）。表示は「目安」扱い。
- v2.0（2026-07、Full 41.8万タグ）はカバーが広い可能性があるが Civitai ログインが要り未検証。
